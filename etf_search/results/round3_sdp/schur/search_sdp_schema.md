# Schur-complement SDP artifacts

`search_sdp_cert.py` builds an exact polynomial model in unit-circle phase coordinates. The three-fixed-point models include all 120 upper-triangular two-by-two Schur-complement minors before removal of identically zero expressions. Every layout enforces the real Gram tightness and the phase-circle equations. The sparse layout uses shared moments across pair-incidence blocks and enforces equation multiples supported by current moments. The dense layout uses all monomials through degree four and enforces every equality multiple whose total degree is at most four.

- `model.json` lists the phase coordinates, polynomial coefficients, equality rows, moment order, and PSD bases. A monomial is a sorted list of repeated zero-based variable indices. The empty list represents 1. Coefficients use rational strings in the basis `(1, sqrt(2), sqrt(5), sqrt(10))`. Each equality row is an equation name and its multiplying monomial. The first row has a null name and imposes normalization of the constant moment.
- `raw_solver.npz` stores `x`, `y`, and `s` from SCS, along with `equality_dual` and each unpacked `psd_dual_N`. The packed PSD segments of `y` and `s` use the lower triangle with column-major order and sqrt(2) scaling for off-diagonal entries.
- `certificate.json` is written if SCS returns an infeasibility dual with negative normalization. Each equality multiplier is a sparse rational polynomial. PSD terms are given as integer factor rows `L` with a positive common denominator `d`. Substitute the exact equations and factors to compute the polynomial `r = -1 - sum(h_i*m_i) - sum(norm(L_i^T*v_i/d)^2)`. For each radical `sqrt(k)`, form rational lower and upper endpoints `isqrt(k*N^2)/N` and `(isqrt(k*N^2)+1)/N`, where `N` is stored as `radical_interval_denominator`. Evaluate each coefficient of `r` by interval arithmetic with the signs of its exact rational coordinates. The sum of the maximal endpoint magnitudes bounds `|r|` over the unit box. `search_sdp_verify.py` recomputes this bound with integer arithmetic. A sum strictly below 1 proves infeasibility because each `h_i` vanishes and each squared norm is nonnegative at a solution.
- `summary.json` records authoritative SCS status, configuration and diagnostics. `guard.json` records exit status, elapsed wall time and sampled process-tree RSS. `solver.log` holds the solver trace. The preserved `solver_api_error.log` records the first launch error from an SCS 3.3 API change, followed by corrected runs.

The implementation was checked by comparing all generated polynomial values against an independent complex Gram construction and direct real-block calculations. A toy SDP for `1 + x^2 = 0` exercised the SCS dual, sign normalization and exact rational PSD factor reconstruction. Its exact residual bound is approximately `9.77e-12`.
